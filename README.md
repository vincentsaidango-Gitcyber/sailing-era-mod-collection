# Sailing Era Mod Collection
# 风帆纪元 Mod 整合包

An unofficial collection of quality-of-life mods for Sailing Era, featuring a graphical installer and independent mod management.

《风帆纪元》非官方 Mod 整合包，提供多项改善游戏体验的功能，支持图形化一键安装、自定义设置及独立 Mod 管理。

『風帆紀元（Sailing Era）』のプレイ環境を改善する非公式 Mod パックです。GUI インストーラー、設定値の変更、各 Mod の個別管理に対応しています。
